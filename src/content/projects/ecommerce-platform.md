## Overview

A team-based full-stack e-commerce platform developed as a graduation project for browsing and purchasing electronic products.

## Problem

An online electronics store needs more than a product catalog. Customers need a clear interface for interacting with products while the application requires reliable backend logic and persistent data storage.

## Solution

The project combined a React-based frontend with backend functionality implemented using Laravel/PHP and Node.js, with MySQL used for persistent data storage.

## My Contribution

I worked across multiple parts of the platform alongside the project team, contributing to frontend, backend, database-related functionality, and system integration.
